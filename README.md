# Age of War 플래시 게임 역컴파일 소스

`Age of War` 플래시 게임(SWF)의 전체 역컴파일 결과를 보관한 저장소다. 3DS 포트 저장소(`Age-of-War-3DS`)와 분리해 관리하며, 포트 작업의 참고 자료와 아카이브 용도로만 쓴다. 원본 SWF를 비롯해 스크립트, 스프라이트, 사운드, 텍스트, 에셋을 모두 포함한다.

역컴파일 결과의 출처는 [Decompiled-flash-games-archive](https://github.com/erupturatis/Decompiled-flash-games-archive)의 Age of War 폴더다. 원본 SWF는 [archive.org의 flash_age_of_war](https://archive.org/details/flash_age_of_war)에서 가져왔다.

원본 게임에 대한 저작권이나 배포 권리를 주장하지 않으며, 재배포 라이선스를 부여하지도 않는다.
